Disposition Shiny App

Purpose

A single-view exploration tool for subject disposition data.

Rationale

Exploring subject disposition data often requires navigating multiple SDTM datasets. This application consolidates key information into one interface, enabling faster and more intuitive review of subject-level outcomes.

Key Features / Advantages
Displays the most important subject disposition information in a single integrated view
Supports TFL programming by helping identify inconsistencies or conflicts in data
Provides sponsors with an overview of study disposition by subject, site, or treatment arm
Adds an additional diagnostic layer for detecting potential data or programming issues (e.g., dates, visits, epochs, treatments)
Data Source

This application uses CDISC Pilot Study SDTM data:
https://github.com/cdisc-org/sdtm-adam-pilot-project
